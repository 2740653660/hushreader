# 步骤 1：核心能力验证说明（Windows）

最后更新：2026-08-11

## 目的

验证 Tauri 外壳能否稳定实现隐阅盒最关键的隐蔽阅读能力。全部通过后才继续开发，不通过则切换 Electron。

## 验证程序

- 位置：`capability-check/win/HushReader-能力验证.exe`
- 说明：临时验证程序，仅用于测试，不是正式产品。

## 在 Windows 上怎么测（约 5 分钟）

1. 把 `HushReader-能力验证.exe` 复制到 Windows 电脑，双击运行。
   - 如果出现“未知发布者”提示，选择“仍要运行”（软件未签名，第一版都是这样）。
2. 出现一个半透明圆角小窗口（说明透明窗口正常）。
3. 逐项检查：

| 检查项 | 操作 | 通过标准 |
|---|---|---|
| 透明无边框 | 观察窗口 | 窗口半透明圆角、无系统边框、能看到后面桌面 |
| 始终置顶 | 打开其他窗口 | 验证窗口始终在最前面，不会被挡住 |
| 拖动 | 按住标题栏拖动 | 窗口能移动 |
| 调整大小 | 拖窗口边缘 | 窗口能改大小 |
| 老板键 F12 | 按 F12 | 窗口隐藏，再按 F12 显示；F12 计数增加 |
| 全局翻页键 | 按 ← → 方向键 | 翻页计数增加（其他程序打开时也有效） |
| 托盘 | 看屏幕右下角托盘 | 有图标；左键单击可隐藏/显示窗口；右键菜单有“显示/隐藏窗口”和“退出” |

4. 点“退出程序”按钮关闭，或从托盘菜单“退出”。

## 需要重点关注的问题

1. 透明窗口在不同电脑/显卡上是否闪烁、卡顿或显示黑底？
2. 快捷键在其他软件（如游戏、输入法）占用时是否冲突或失效？
3. 窗口在显示器分辨率/缩放变化后是否异常？

## 记录方式

把结果（通过/失败 + 现象描述）反馈给开发人员即可。建议至少在一台 Win10 和一台 Win11 上各测一次。
