# 隐阅盒决策记录

本文件只追加已经确认的产品决定。决定改变时新增一条“取代原决定”的记录，不删除历史。

## 2026-08-11

- **D-001 独立 Windows 软件**：最终产品不依赖 ZTools，macOS 和 Linux 推迟。
- **D-002 保留名称与风格**：继续使用“隐阅盒 / HushReader”，以现有简洁书架风格为起点。
- **D-003 第一版优先快速落地**：允许捆绑 So Novel Java 后台，体积和内存后续优化。
- **D-004 下载完再阅读**：不做边下载边看。
- **D-005 用户选择书源**：搜索展示多个结果，不替用户自动选择唯一结果。
- **D-006 第一版不支持网页地址**：只按书名或作者搜索。
- **D-007 保留本地导入**：本地支持 EPUB、TXT、MOBI；下载支持 EPUB、TXT。
- **D-008 第一版只用悬浮阅读器**：暂不做普通大窗口阅读模式。
- **D-009 保留完整隐蔽阅读能力**：置顶、拖动缩放、分离透明度、三种鼠标移出模式、老板键、全局翻页、滚轮翻页、托盘、开机启动、书签、进度和阅读时长都进入第一版；自动翻页明确不需要。
- **D-010 手动更新连载小说**：支持单本和全部检查更新，不做后台自动下载新章节。
- **D-011 统一管理书库**：软件管理默认书库目录，用户可在设置中修改。
- **D-012 关闭到托盘**：主窗口关闭后缩到托盘，托盘菜单负责真正退出。
- **D-013 数据完全本地**：不做账号、云同步、分析和遥测，发布版移除 So Novel 设备信息上报。
- **D-014 GitHub 开源发布**：公开源码和 Windows 安装包，合并项目暂定 AGPLv3并保留上游署名。
- **D-015 软件内完成 GitHub 更新**：展示说明、用户确认、校验并安装，不跳浏览器且不强制更新。
- **D-016 书源规则单独更新**：无需重装软件，更新前备份并支持恢复。
- **D-017 默认快捷键**：老板键默认 F12；全局翻页默认使用键盘左右方向键；所有快捷键均可在设置中自定义。
- **D-018 第一版不购买代码签名**：接受 Windows 的“未知发布者”提示，用免费方式发布，后续再评估购买证书。
- **D-019 GitHub 仓库归属**：公开仓库由产品负责人的 GitHub 账号管理，发布前由其提供账号信息。
- **D-020 书源失效切换**：原书源永久失效时，由用户手动切换到另一个书源并重新匹配章节，保留已有进度和书签；自动切换推迟到后续版本。
- **D-021 书架备份推迟**：书架备份/导出功能推迟到第一版之后。
- **D-022 桌面外壳采用 Tauri**：第一版使用 Tauri 作为桌面外壳，换取更小的安装包和更低的内存占用。开发前先做核心能力验证（透明悬浮窗、置顶、全局快捷键、托盘），验证不通过则切回 Electron（界面代码两边通用，切换成本低）。

## 2026-08-11（补充）

- **D-023 快捷键冲突不得导致程序无法启动**：任何一个全局快捷键被其他程序占用时，程序必须正常启动和运行，只把该键标记为“冲突”并在界面提示，其余快捷键和功能不受影响。这是正式产品的硬性要求。验证程序中发现 Tauri 快捷键插件批量注册、单个失败即中止启动的缺陷后，已改为逐个注册并单独容错。
- **D-024 本机验证程序老板键默认键**：能力验证程序（非正式产品）的老板键默认键由 F12 改为 F9。原因是本验证机的 F12 已被其他程序占用；换键只为了让验证继续。正式产品的默认老板键仍按 D-017 保持 F12，且全部快捷键可在设置中自定义。
