# 隐阅盒产品需求

状态：持续更新  
最后更新：2026-08-11

## 产品概述

隐阅盒 / HushReader 是一款 Windows 独立桌面软件，将小说搜索下载、书架管理和隐蔽悬浮阅读整合在一起。用户搜索小说，从多个书源结果中自行选择，下载完成后加入书架并阅读。

软件将公开发布在 GitHub。普通用户只需安装一个程序，不需要 ZTools、命令行、单独安装 Java 或单独安装 So Novel。

## 主要用户

不熟悉编程和命令行，希望简单完成找书、下载、管理和隐蔽阅读的 Windows 用户。

## 产品优先级

1. 尽快交付完整可用的第一版 Windows 软件。
2. 完整保留并强化 HushReader 的隐蔽悬浮阅读体验。
3. 界面简单，非技术用户不需要理解后台组件。
4. 尽量控制启动速度、内存和安装包大小，第一版完成后继续深度优化。
5. 所有个人阅读数据保存在本机。

## 第一版使用流程

1. 用户通过一个安装包装好软件。
2. 软件打开后进入书架。
3. 用户进入“找书”页面，输入书名或作者。
4. 软件展示多个书源结果和相关信息。
5. 用户选择结果及 EPUB/TXT 格式并下载。
6. 软件展示下载进度、完成状态或恢复办法。
7. 下载完成后自动加入书架。
8. 用户点击书籍，在悬浮窗口中阅读。
9. 下次启动时恢复书架、阅读位置和个人设置。

## 第一版功能

### 桌面软件

- 独立 Windows 应用，不依赖 ZTools。
- 一个安装包包含所有必要运行组件。
- 关闭主窗口时默认缩到系统托盘。
- 托盘菜单提供显示、隐藏和真正退出。
- 支持设置为开机启动。
- 延续现有隐阅盒简洁的明暗主题风格。

### 搜索与下载

- 按书名或作者搜索。
- 展示多个书源结果，由用户选择。
- 条件允许时展示书名、作者、书源、简介、连载状态、最新章节、更新时间和字数。
- 下载格式支持 EPUB 和 TXT。
- 展示下载进度、成功、失败和重试状态。
- 下载完成前不能开始阅读。
- 下载成功后自动加入书架。
- 使用统一管理的书库文件夹，设置中可修改位置。
- 下载失败不得损坏书架或已有书籍。

### 本地书籍导入

- 支持 EPUB、TXT、MOBI。
- 尽量保留现有元数据、封面、章节解析和文本编码能力。
- 防止意外重复导入，同时允许修复失效文件路径。

### 书架

- 卡片和列表视图。
- 按书名或作者搜索。
- 分类、排序、元数据编辑、封面、删除和批量操作。
- 阅读进度、读完状态、书签和阅读时长。
- 打开书籍所在文件夹。

### 连载小说更新

- 单本检查新章节。
- 全部检查更新。
- 第一版由用户手动触发，不在后台自动下载新章节。
- 保存下载书籍与原书源的关系。
- 更新后保留阅读进度、书签、分类和用户修改的元数据。
- 原书源失效或无法匹配时，给出明确说明和恢复选择。

### 隐蔽悬浮阅读器

- 第一版只使用悬浮窗口阅读，不要求普通大窗口阅读模式。
- 窗口始终置顶。
- 可拖动和调整大小。
- 背景透明度和整体/文字透明度分别调节。
- 鼠标移出有三种模式：不隐藏、只保留进度、完全隐藏。
- 可配置老板键（默认 F12），立即隐藏或显示阅读窗口。
- 可配置全局上一页和下一页快捷键（默认键盘左右方向键）。
- 滚轮翻页。
- 可配置添加书签快捷键（默认 Ctrl+B）。
- 改变窗口、字体或重启软件后仍能准确恢复阅读位置。
- 保存书签和阅读时长。
- 不需要自动翻页。

### GitHub 应用内更新

- 在软件内检查 GitHub Releases 新版本。
- 每天最多自动检查一次，同时提供手动“检查更新”。
- 安装前展示版本号和更新说明。
- 不强制更新。
- 用户确认后在软件内下载、校验并安装，必要时重启。
- 更新失败不能影响阅读或损坏当前版本。

### 书源规则更新

- 与完整软件更新分开检查。
- 用户可在软件内更新书源规则。
- 更新前备份当前可用规则，新规则失败时可恢复。

### 隐私

- 不注册账号。
- 不做云同步。
- 不做数据分析或遥测。
- 不上报设备信息。
- 书籍、历史、书签、设置和阅读统计均保存在本机。

## 发布与许可证

- 在 GitHub 公开源码和 Windows 安装包。
- 合并发布项目暂定采用 AGPLv3，如后续法律审查需要再做兼容调整。
- 保留上游项目署名和修改说明。
- 提供构建和打包文档。
- 提供清晰的内容使用及著作权免责声明。

## 后续功能

- 重构或替换 Java 下载后台，进一步降低安装包和内存占用。
- macOS 和 Linux。
- 普通大窗口阅读模式。
- 导出或备份书架数据。
- 自动后台检查或下载新章节。
- 边下载边阅读。
- 粘贴网页地址直接下载。
- 只有经过新的隐私决定后，才考虑跨设备同步。

## 第一版明确不做

- 手机应用。
- macOS 或 Linux 版本。
- 自动翻页。
- 账号和云同步。
- 强制应用更新。
- 粘贴网页地址下载。
- 下载完成前阅读。

## 待确认问题

- 默认书库目录和旧数据迁移方式（由工程方案确定后确认）。

## 已确认的界面与发布细节

- 默认快捷键：老板键 F12、全局翻页为键盘左右方向键、书签为 Ctrl+B，均可自定义。
- 第一版不购买代码签名，安装时会出现“未知发布者”提示。
- 发布仓库由产品负责人的 GitHub 账号管理。
- 原书源永久失效时手动切换到其他书源并重新匹配章节。
- 书架备份/导出推迟到第一版之后。
